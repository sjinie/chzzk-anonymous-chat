# 치지직 익명 채팅 뷰어 v1.1.0

**메인 페이지의 로그인과 영상 재생은 그대로 두고, 치지직 기본 채팅창을 익명으로 표시합니다.**

## 1.1.0 변경점

- 기본 모드를 직접 구현한 채팅 UI에서 **치지직 원래 팝업 채팅 UI**로 변경했습니다.
- Chrome의 `iframe credentialless`를 사용해 채팅 프레임에만 별도의 임시 쿠키/스토리지 컨텍스트를 적용합니다.
- **닉네임 클릭 → 기본 정보 카드**, 팔로우 날짜, 네이티브 배지·이모티콘·클린봇·크기 조절 등 치지직의 익명 공개 UI를 그대로 사용합니다. 계정 상태와 서버 응답에 따라 카드에서 공개되는 정보는 다를 수 있습니다.
- 상단 선택창에서 기존 **간단 채팅** 모드로 바꿀 수 있습니다.
- `credentialless` 미지원 브라우저는 기존 간단 채팅으로 대체합니다. 지원되지 않는 브라우저에 일반 로그인 iframe을 넣지는 않습니다.
- 팝업 채팅 페이지와 하위 프레임에는 확장 UI를 삽입하지 않아 중첩 실행을 방지합니다.

## 기존 1.0.0에서 업데이트

편한 방법 하나를 선택하세요.

### 기존 확장 유지

1. 새 ZIP을 압축 해제합니다.
2. 새 폴더 안의 파일과 `tests` 폴더를 **기존에 Chrome에 로드했던 폴더 안으로 덮어씁니다**. `manifest.json` 내용의 버전이 `1.1.0`인지 확인하세요.
3. `chrome://extensions`에서 기존 확장 카드의 **새로고침** 버튼을 누릅니다.
4. 치지직 방송 탭도 새로고침합니다.

### 새 폴더로 로드

1. `chrome://extensions`에서 **기존 1.0.0 확장을 먼저 끕니다**. 두 버전을 동시에 켜지 마세요.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. ZIP을 푼 `chzzk-anonymous-reader-v1.1.0` 폴더를 선택합니다. 이 폴더 안에 `manifest.json`이 있어야 합니다.
4. 방송 탭을 새로고침합니다. 새 버전이 정상 동작하면 기존 확장은 제거해도 됩니다.

별도 서버, API 키, 로그인 쿠키 입력, npm 설치는 필요 없습니다. 로드한 폴더는 지우거나 옮기지 마세요. Chrome 데스크톱 120 이상을 대상으로 합니다.

## 사용

- 라이브 방송의 기존 채팅 영역에 활동 제한 안내가 감지되면 자동으로 열립니다.
- 자동으로 열리지 않으면 오른쪽 아래 **익명 채팅 보기**를 누릅니다.
- 상단 **기본 채팅**: 치지직 원래 UI입니다. 채팅 닉네임을 눌러 익명 상태에서 공개되는 정보를 확인할 수 있습니다.
- 상단 **간단 채팅**: 1.0.0의 경량 읽기 전용 UI입니다. 기본 UI가 로드되지 않거나 치지직이 변경되면 이 모드로 바꿔 보세요.
- **원래 채팅**: 익명 프레임/연결을 닫고 기존 채팅창으로 돌아갑니다.
- 표시 여부와 모드 선택은 현재 탭에서 채널별로 유지됩니다. 새로고침하면 초기화됩니다.
- 방송 페이지 안에서 다른 라이브로 이동하면 새 채널로 전환합니다.

## 익명 범위와 제한

- **밴 해제나 권한 복구 기능은 없습니다.** 메인 계정의 팔로우·후원·구독·댓글·채팅 제한은 그대로입니다.
- 기본 모드도 익명 상태이므로 로그인 필요한 기능은 지원하지 않습니다. 메시지 신고·사용자 차단·선물 등의 메뉴가 보인다고 실제 사용 가능하다는 의미는 아닙니다.
- **익명 상태는 채팅 iframe 안에만 적용됩니다.** iframe에서 열린 새 창은 Chrome의 일반 컨텍스트여서 기존 로그인 상태일 수 있습니다. 외부 창까지 익명으로 만든다는 기능은 아닙니다.
- 채팅 iframe 안에서 로그인을 시도하지 않는 것을 권장합니다. 이 확장의 목적은 로그인 없는 공개 채팅 열람입니다.
- 기본 UI의 모든 기능을 보장하지는 않습니다. 익명 접근을 서버가 거절하거나 별도 인증이 필요한 정보는 표시할 수 없습니다. 로그인·연령 확인 등 추가 인증을 대신 수행하지 않습니다.
- 실제 로그아웃, 계정 변경, 쿠키 삭제를 하지 않습니다. 플랫폼의 약관과 운영정책을 준수하세요.

## 간단 채팅 모드

- 익명 공개 API에서 채팅 채널 ID와 읽기용 토큰을 받아 `uid: null`, `auth: 'READ'`로 연결합니다.
- HTTP 조회는 `credentials: 'omit'`이며, 이 확장에서 시작한 치지직 채팅 소켓에만 Cookie/Set-Cookie 제거 규칙을 적용합니다. 규칙 설치 실패 시 연결하지 않습니다.
- 허용된 소켓 명령은 연결/heartbeat/최근 채팅 조회뿐입니다. 메시지 전송 명령은 코드에서 차단합니다.
- 최근 50개 요청, 재연결, 표시 일시정지, 글자 크기 조절, 최신 채팅 이동을 지원합니다.
- 화면 최대 400개와 일시정지 대기 최대 400개를 유지합니다. 대기 초과분은 오래된 순서로 생략하고 수를 표시합니다.
- 간단 모드에는 기본 UI의 닉네임 정보 카드가 없습니다.

## 권한과 개인정보

1. `chzzk.naver.com`의 content script: 라이브 주소/제한 안내 감지, 표시 영역 배치. 기본 모드는 그 페이지 아래에 치지직 자신의 `/live/{채널}/chat` iframe을 직접 넣습니다. 치지직의 iframe 보안 정책을 제거하거나 무력화하지 않습니다.
2. `declarativeNetRequestWithHostAccess`와 API/채팅 소켓 호스트 권한: **간단 모드**의 익명 공개 API 조회 및 소켓 쿠키 제거를 위해 유지됩니다. 규칙은 이 확장의 소켓만 대상으로 하므로 일반 치지직 페이지 요청에는 적용되지 않습니다.
3. 쿠키 읽기, 방문 기록, 비밀번호 접근 권한은 요청하지 않습니다. 확장 자체의 분석·수집·중계 서버는 없습니다. 기본 모드는 치지직 원래 페이지의 일반 네트워크 요청을 사용합니다.
4. 확장 자체는 채팅과 토큰을 파일이나 브라우저 저장소에 기록하지 않습니다. 기본 모드에서는 치지직 페이지가 브라우저의 임시 격리 파티션에 데이터를 저장할 수 있으며, 이 파티션은 메인 문서를 벗어나거나 새로고침하면 교체됩니다.
5. 간단 모드의 사용자 텍스트는 HTML로 실행하지 않습니다. 이모티콘은 허용된 pstatic 이미지 호스트만 로드합니다.

## 문제 해결

- 로드 후 열려 있던 방송 탭을 반드시 새로고침하세요. 확장 카드의 새로고침만으로 기존 content script가 교체되지는 않습니다.
- 두 버전이 겹쳐 보이면 기존 확장을 끄고 방송을 새로고침하세요.
- 기본 모드가 비어 있거나 오류가 나면 상단에서 **간단 채팅**을 선택하세요. 확장과 브라우저가 사이트별로 iframe/네트워크 요청을 제한하는지도 확인하세요.
- 간단 모드의 연결 오류는 확장이 필요한 API/소켓 사이트에 접근할 수 있는지 확인하세요. 치지직 본 사이트 하나만 허용하면 별도 API 권한이 빠질 수 있습니다.
- 익명 파티션을 새로 만들고 싶으면 메인 방송 페이지를 새로고침하세요. 프레임만 닫았다 다시 열면 같은 메인 문서의 임시 파티션을 재사용할 수 있습니다.
- 치지직 페이지 구조, 익명 정책, 비공식 간단 채팅 프로토콜이 바뀌면 수정이 필요할 수 있습니다.
- 제거는 `chrome://extensions`에서 해당 확장을 삭제하면 됩니다. 계정 상태는 바뀌지 않습니다.

## 검증 범위

2026-10-18, 요청받은 방송에서 확인했습니다.

- 로그인된 메인 페이지의 활동 제한 안내가 그대로인 상태에서, 기본 채팅 iframe의 `credentialless`와 내부 `window.credentialless`가 모두 `true`인 것을 확인했습니다.
- 같은 탭에 이 버전의 `content.js`를 시험 적용하여 실제 기본 채팅과 네이티브 배지/이모티콘이 표시되는 것을 확인했습니다.
- 채팅 닉네임을 열어 실제 기본 정보 카드와 팔로우 날짜가 표시되는 것을 확인했습니다.
- iframe의 입력 안내는 **채팅에 참여하려면 로그인 해주세요**였습니다. 메인 계정을 로그아웃하지 않았습니다.
- 간단 모드의 익명 API, 실시간 수신과 기존 단위 테스트도 유지했습니다.
- Native 모드용 DOM 테스트는 `tests/native-content.test.mjs`에 있습니다.

사용자 브라우저에 확장 설치/교체를 대신 수행하지는 않았습니다. 브라우저에 unpacked extension으로 로드하는 전체 설치 테스트와 서비스의 모든 프로필/팝업 기능까지 확인한 것은 아닙니다.

Node.js 20 이상에서 테스트:

```sh
node --test tests/*.mjs
```
