# 치지직 익명 채팅 뷰어 v1.0.0

치지직 로그인과 영상 재생은 그대로 두고, 로그아웃 상태에서 공개되는 채팅만 별도 익명 연결로 읽는 Chrome Manifest V3 확장 프로그램입니다.

**채팅 전송, 계정 전환, 밴 해제 기능은 없습니다.** 실제 로그아웃이나 쿠키 삭제도 하지 않습니다. 확장 프로그램의 채팅 소켓에서만 Cookie 헤더를 제거하고, 공개 API는 `credentials: 'omit'`으로 조회합니다.

## 설치

1. ZIP을 내려받아 압축을 풉니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json` 파일이 들어 있는 **chzzk-anonymous-reader 폴더**를 선택합니다. ZIP 자체나 상위 폴더를 선택하지 마세요.
6. 열려 있던 치지직 방송 탭을 새로고침합니다.

별도 서버, API 키, 로그인 쿠키 입력, npm 설치는 필요 없습니다. 로드한 폴더를 지우거나 다른 곳으로 옮기면 확장이 작동하지 않을 수 있습니다. 장기 보관할 위치로 먼저 옮겨 둔 후 로드하세요. Chrome 데스크톱 120 이상을 대상으로 합니다.

## 사용

- 방송의 채팅 영역에 **활동 제한** 안내가 감지되면 읽기 창이 자동으로 표시됩니다.
- 자동으로 열리지 않으면 화면 오른쪽 아래 **익명 채팅 보기**를 누르세요.
- **원래 채팅**을 누르면 익명 연결을 종료하고 기존 채팅창으로 돌아갑니다.
- 선택은 현재 탭에서 채널별로 유지되고, 새로고침하면 초기화됩니다.
- 최근 50개 채팅을 요청한 뒤 실시간 메시지를 수신합니다. 서버가 실제 제공하는 개수는 다를 수 있습니다.
- 재연결, 글자 크기 조절, 표시 일시정지, 최신 채팅 이동을 지원합니다.
- 화면에는 최대 400개, 일시정지 대기열에도 최대 400개를 보관합니다. 일시정지 중 초과한 메시지는 오래된 순서로 생략하며 개수를 표시합니다. 채팅 로그 수집·내보내기 기능은 없습니다.
- 방송 페이지 안에서 다른 라이브로 이동하면 채널을 자동 전환합니다. 방송 종료·네트워크 오류 시 간격을 두고 재확인합니다.

## 권한과 개인정보

- `declarativeNetRequestWithHostAccess`: 이 확장에서 시작한 치지직 채팅 WebSocket 연결의 Cookie 및 Set-Cookie 헤더만 제거합니다. 일반 치지직 페이지의 요청에는 적용하지 않습니다.
- `api.chzzk.naver.com`: 익명 방송 상태 및 채팅 채널 ID 조회.
- `comm-api.game.naver.com`: 익명 읽기용 채팅 토큰 조회.
- `wss://*.chat.naver.com/*`: 치지직 공개 채팅 소켓 수신과 해당 연결의 쿠키 제거. 개발자 모드 로드용 권한 선언입니다.
- `chzzk.naver.com` content script: 라이브 주소/활동 제한 문구 감지와 뷰어 배치.
- 쿠키 읽기, 방문 기록, 비밀번호 접근, 외부 분석·중계 서버 권한은 요청하지 않습니다.
- 채팅과 토큰은 메모리에서만 사용하고 파일·브라우저 저장소에 기록하지 않습니다.
- 치지직 이모티콘은 허용된 pstatic 이미지 호스트에서 직접 로드합니다. 그 밖의 URL은 실행하거나 자동으로 열지 않습니다.

## 한계와 문제 해결

- 비공식 웹 채팅 프로토콜을 사용하므로 치지직 변경에 따라 수정이 필요할 수 있습니다.
- 익명 서버가 제공하지 않거나 접근을 거절한 채팅은 표시할 수 없습니다. 로그인·연령 확인 등 추가 인증을 대신 수행하지 않습니다.
- 밴과 사람 단위 활동 제한은 그대로 유지됩니다. 팔로우·후원·구독·댓글·채팅 권한을 복구하지 않습니다. 플랫폼의 약관 및 운영정책을 준수하세요.
- 네이티브 채팅 UI의 완전 복제는 아닙니다. 일부 배지·특수 효과·신규 메시지 유형은 생략될 수 있고, 이모티콘 URL이 허용된 호스트가 아니면 코드 형태로 표시됩니다.
- 확장이 열리지 않으면 방송 탭을 새로고침하고 수동 버튼을 눌러 보세요. 치지직 UI 변경 시 자동 배치 대신 오른쪽 부유 창으로 표시될 수 있습니다.
- 연결 오류가 계속되면 `chrome://extensions`에서 확장이 켜져 있는지와 필요한 사이트 접근 권한을 확인하세요. 치지직 도메인 하나만 허용하면 별도 공개 API/소켓 도메인 권한이 빠질 수 있습니다.
- 업데이트 시 파일을 교체하고 확장 카드의 새로고침 버튼을 누른 다음 방송 페이지도 새로고침하세요.
- 제거는 `chrome://extensions`에서 해당 확장의 **삭제**를 누르면 됩니다. 사이트의 계정 상태는 바뀌지 않습니다.

## 검증 범위

2026-10-18, 요청받은 방송을 기준으로 다음을 확인했습니다.

- 쿠키 없는 공개 API 조회 및 `uid: null`, `auth: 'READ'` 소켓 연결 성공.
- 최근 채팅과 실시간 채팅 수신 성공.
- 동일 소스 기반 로컬 브라우저 검증 화면에서 채팅 렌더링, 제한 안내 감지/표시 종료, 일시정지/재개, 글자 크기 변경 확인.
- Node 자동 테스트 11개 통과: 익명 HTTP, 허용된 발신자/명령, 쿠키 제거 규칙 범위, 보호 규칙 실패 시 연결 중단, 메시지 파싱, 읽기 전용 명령 제한, 종료 후 늦은 응답 무시 등.

**확장을 실제 Chrome에 로드한 통합 테스트는 이 실행환경에서 격리 Chrome 프로세스를 시작하지 못해 실시하지 못했습니다.** 따라서 설치 승인/manifest 로드, 확장 origin iframe, 실제 DNR 적용까지 모두 검증되었다는 의미는 아닙니다. 사용자 브라우저에는 설치하거나 설정을 변경하지 않았습니다.

개발용 단위 테스트는 Node.js 20 이상에서 다음과 같이 실행할 수 있습니다.

```sh
node --test tests/reader.test.mjs
```

프로토콜 확인에 참고한 공개 자료:
- https://github.com/kimcore/chzzk/blob/main/src/chat/chat.ts
- https://github.com/kimcore/chzzk/blob/main/src/chat/types.ts
- https://github.com/sdkim96/chzzk-go/blob/v0.6.0/unofficial/chat.go
- https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest

## 파일 구조

- `manifest.json`: MV3 설정과 좁은 사이트 권한.
- `background.js`: 익명 공개 API 조회와 연결별 쿠키 제거 규칙.
- `content.js`: 라이브/제한 감지, 채널 전환, iframe 배치.
- `chat-client.mjs`: 읽기 전용 프로토콜, heartbeat, 재연결.
- `viewer.html`, `viewer.css`, `viewer.js`: 격리된 채팅 UI.
- `tests/reader.test.mjs`: 의존성 없는 Node 테스트.
